# Hey, Human

A VS Code extension that plays a sound whenever Claude Code needs you: a permission
prompt, an idle wait for input, or the end of a turn.

## How it works

1. The extension adds two hooks (`Notification`, `Stop`) to `~/.claude/settings.json`.
   Each hook writes its JSON payload to `~/.claude/hey-human/events/`.
2. Every VS Code window running the extension watches that folder and plays a sound
   when an event arrives. By default only the window whose workspace contains the
   Claude session's working directory plays it.

It works for Claude Code in the integrated terminal, an external terminal, and the
Claude Code VS Code extension, because all of them read the same settings file.

## Run it

```sh
npm install
```

- **Try it:** open this folder in VS Code and press `F5`. In the new window, accept
  the "Install hooks" prompt, then restart any running Claude Code session.
- **Install it permanently:**
  ```sh
  npm run package
  code --install-extension hey-human-0.3.1.vsix
  ```

## Commands

| Command | What it does |
| --- | --- |
| Hey, Human: Choose Sound... | Pick a sound per moment, with a preview as you move through the list |
| Hey, Human: Play Test Sound | Plays the "needs input" sound |
| Hey, Human: Toggle Mute | Same as clicking the bell in the status bar |
| Hey, Human: Install Claude Code Hooks | Adds the hooks (backs up `settings.json` to `settings.json.bak`) |
| Hey, Human: Remove Claude Code Hooks | Removes only this extension's hooks |
| Hey, Human: Show Log | Opens the output channel |

## Settings

| Setting | Default | Meaning |
| --- | --- | --- |
| `heyHuman.enabled` | `true` | Master switch |
| `heyHuman.needsInputSound` | `faaah` | Sound for permission prompts and idle input waits |
| `heyHuman.finishedSound` | `faaah` | Sound when Claude finishes its turn |
| `heyHuman.customSoundPath` | `""` | `.wav` or `.mp3` used by any sound set to `custom` |
| `heyHuman.volume` | `70` | 0-100 |
| `heyHuman.onlyWhenUnfocused` | `false` | Stay silent while the window is focused |
| `heyHuman.matchWorkspace` | `true` | Only play in the window that owns the session's directory |
| `heyHuman.cooldownMs` | `1500` | Minimum gap between sounds |

Set either sound to `none` to silence that moment.

## Project layout

| Path | Role |
| --- | --- |
| `src/extension.ts` | Activation, commands, status bar, and the "should this play?" decision |
| `src/config.ts` | Settings, paths, and the hook event to setting mapping |
| `src/hooks-installer.ts` | Adds and removes the hooks in `~/.claude/settings.json` |
| `src/event-watcher.ts` | Watches the events folder and reports each event once |
| `src/audio-player.ts` | Resolves a sound name to a file and plays it per platform |
| `src/logger.ts` | Output channel |
| `sounds/` | Bundled sounds; a new file here also needs adding to both `enum` lists in `package.json` |
| `scripts/generate-chime.js` | Regenerates `sounds/chime.wav` |

## Notes

- Sound is played with `afplay` (macOS), PowerShell `MediaPlayer` (Windows), or the
  first of `ffplay`, `paplay`, `mpg123`, `aplay` that works (Linux). Volume is ignored
  by `mpg123` and `aplay`.
- The hook command is a POSIX shell one-liner; on Windows it needs Git Bash, which
  Claude Code already uses to run hooks.
- The meme `.mp3` files are third-party clips. Check their licensing before publishing
  the extension to the Marketplace; `chime.wav` is generated by this repo and is safe.
